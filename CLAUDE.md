# Bayesian ad management

Statistical ad management and decision intelligence. Read README.md and spec/ first.

## Status reporting

Every component of the project reports to one project manager. A request for this folder's
workstream opens each morning, and a note appears in the Claude Code session working here when
one is waiting. Answer it at a quiet moment before the session ends, never mid-build: one JSON file
per workstream, submitted with the command the note gives. The rules and the registry are in
`/Users/atma1/gh_all/atmaos/pm_pilot/STATUS_REPORTING.md`. "No change, and this is what I checked"
is a valid answer. No secrets, no estimates. Work that starts in a folder not on the registry is
registered there first.
