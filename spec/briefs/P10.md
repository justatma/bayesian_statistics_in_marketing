Notes: the engine makes no LLM calls (I4); prose comes from templates and the phrasing registry. The claims checker (G5) parses narrative and rejects: a number that matches no bundle quantity at registry rounding, a below-floor rate stated as a finding, a causal verb without randomized evidence, a marginal quantity without its caveat, a comparative without a comparison whose decision basis supports it; each rejection names the offending token. Render writes HTML to `RenderedReport.html_path`; G7 refuses missing provenance (lists quantity ids); a client report refuses synthetic data while internal/demo reports carry the watermark; the not-knowable block shows available and required as integers and not the estimate; the diagnostics appendix shows real values from the DiagnosticsReport. Optional PDF via the `pdf` extra only if weasyprint is installed; HTML is the deliverable. The report will be filmed for the client demo video, so make the HTML clean and legible: semantic structure, readable at 1280 px wide, no external assets.
