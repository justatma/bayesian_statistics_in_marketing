Facts pack (verified by the integrator; do not re-derive):
- `pull(platform, config, window) -> PlatformPull` (data_contract/connectors/pull.py:89). Raises `ValueError` on a bad window or missing account, `MissingCredential`/`ConnectorError`/`ReplayMiss` (all `ConnectorError`, http.py) on HTTP failures. `PlatformPull` (core/data.py:65): `pull_id`, `account_id`, `window`, `rows: list[PerformanceRow]`, `quarantined`, `notes`, `empty_account`, `timezone`, `account`, `pulled_at`.
- `PerformanceRow` (core/data.py:17): `entity_ids` keys account/campaign/ad_set/ad, `entity_names` same keys, `objective`, `date`, `impressions`, `clicks`, `spend: Money`, `conversions_observed`, `conversions_reported`, `revenue_reported: Money | None`, `attribution_window`. `Money(amount: Decimal, currency: str)` (core/money.py:16). Store money as `str(amount)` text plus currency.
- Recording: `Transport.from_env()` (http.py:173) reads `BAYES_RECORD_DIR` when `pull()` starts, stages exchanges in a temp dir beside the target, and `commit_recording()` moves them to the target only on success; a failed pull leaves no directory. So an error poll has `recording_dir` None or a path that does not exist; decide which and record it as an open question if the test does not settle it.
- Redaction: `http.redact_text(text)` (http.py ~line 104) blanks every `CREDENTIAL_ENV` value (http.py:39) present in env and the token shapes, including `access_token=<value>` (B1). Use it on the error text; no new redaction function.
- Account time zone for the window: the latest ok poll's `timezone`, else `config.timezone` (`ClientConfig`, core/records.py:83). Today = `clock.now()` in that zone; window = `lookback_days` dates ending today inclusive.
- `poll_id` = `"poll_" + sha256(f"{client_id}|{platform}|{started_at.isoformat()}").hexdigest()[:8]`.
- SQLite: `sqlite3` stdlib. Read-write open runs `SCHEMA` (idempotent), sets `PRAGMA journal_mode=WAL`; every connection `PRAGMA busy_timeout=5000`; read-only opens `file:<path>?mode=ro` with `uri=True` and never creates the file. The triggers raise `sqlite3.IntegrityError` with `live store is append-only`.
- `prune` age comes from the store's `started_at` for the poll named by the directory; directories naming no stored poll are left alone.
