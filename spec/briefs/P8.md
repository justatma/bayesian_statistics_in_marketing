Credentials: read only from environment variables named in `.env.example` (META_ACCESS_TOKEN, GOOGLE_ADS_CLIENT_ID/SECRET/REFRESH_TOKEN, LINKEDIN_ACCESS_TOKEN, GA4_PROPERTY_ID). Never read the `.env` file yourself, never print or log a credential, and make no network call: the tests block sockets.
Recordings: do NOT fabricate recordings. Build a replay layer (`BAYES_REPLAY_DIR` serves every exchange from files) and a record mode (`BAYES_RECORD_DIR`) that writes `request.json` plus each exchange with Authorization headers, tokens and secrets replaced by "REDACTED". The integrator captures real recordings with your record mode after you finish. Your gate is therefore: every P8 test passes except the four `_replay_parses` tests and `empty_account_flagged`, which may fail only for missing recordings; prove the replay path with recordings you generate in your own unit tests under `tests/unit/p8/` from fixture responses shaped exactly as the facts packs document (mark them clearly as unit fixtures, not recordings). Document the record command in `data/recordings/README.md`.
Notes: http via httpx only here; retries and pagination per facts packs; timezone from the account (C2); a re-pull gets a new pull_id (C4, include pulled_at in the id payload); empty account → empty_account=True, no quarantine (C6).
