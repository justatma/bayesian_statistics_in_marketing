## Open questions

1. The registry holds no column headings or header-row labels, so the page uses record field names and metric keys (INFERRED list above). If readable headings are wanted, they need keys in `phrasing.yaml` `live` (integrator-owned); `view.py` and the templates would then read them.
2. The spec's dependency rule (§2) lists `reporting.render` but not `claims`; the facts pack points at `claims.vocab` formatters. `view.py` does not import `claims`: it formats from the `rounding` block of the `phrasing` passed in, with the same shapes.
3. C7 says every percentage shows its counts, but `finding_lines` estimates and intervals in the engine section are percentages with no counts (for ctr). The frozen check runs without an engine section. Left as `finding_lines` gives them.
4. The `$` symbol for USD is a literal in `view.py` (`_SYMBOL`); the registry has no currency symbols.
