INFERRED

- Population logit-mean priors are Normal with the exact mean and sd of logit(p), p ~ the approved Beta record (digamma/trigamma). Population log-CPM prior likewise from the CPM Gamma record; the CPM pooling scale is half-normal with that sd (no registry record for it).
- `order_value_log_sd` serves both the within-ad sd of log order value and the between-ad pooling scale. `logit_scale_*` serve the ad scales, the scales of levels above the ad, and the random-walk innovation scales.
- A level above the ad enters only when it has more than one group in the data (one group is confounded with the population mean).
- `random_walk`: one shared daily walk per stage on the logit scale, pinned at 0 on day one; per-ad CTR/CVR in the parquet are the last day's.
- Order value with an orders file enters through sufficient statistics (n, mean and SS of log values), exact for the log-normal likelihood. AOV column is `exp(mu + sd²/2)`.
- Fractional reported conversions are summed per ad over days before the gamma_obs term (exact, shared rate φ). An ad whose total is 0 gets no gamma term; its CVR comes from the pool and derive marks it prior-only through `n.conversions = 0`.
- Binomial cvr stage: an integral reported count (within 1e-9) is used as a count and flags platform-modeled; a fractional one raises ValueError naming the gamma_obs stage.
- All four stages are required; ctr `beta_binomial` is refused (no overdispersion prior exists); ctr and cvr must be pooled for coupling.
- `flag.lag_adjusted` is written 0 on NUTS states because the likelihood is exact (§5.6 C2); `flag.lag_exact` records that lag was present. `route.too_few_ads` is 0 on NUTS states.
- `flag.aov_source` is not written for the log-normal value stage (derive would add the conjugate "improper reference prior" notice, false here); `flag.aov_orders_file` is written instead. Compound gamma writes `flag.aov_source = 2` (placeholder k notice is true).
- JAX x64 enabled at sampler import (counts reach 1e6+).
- Diagnostics report id is `"dg_" + sha8` (no `dg_` in `ID_PREFIXES`); `ppc` empty, `loo` None (P6 computes them).
- SBC design: one day, spend 100 per ad (`SBC_SPEND_PER_AD`, a design input, not a bound), one chain, registry warmup, `draws // n_draws` thinning; ranks 10 population parameters plus ctr/cvr/cpm/aov per ad.
